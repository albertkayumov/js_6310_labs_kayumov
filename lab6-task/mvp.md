# Функциональные требования к MVP

## Основной функционал сайта рекламного агентства

### Навигация и структура сайта
1. Адаптивный дизайн для мобильных устройств
2. Навигационное меню между разделами сайта
3. Главная страница с основными секциями

### Портфолио работ
1. Отображение кейсов работ агентства
2. Галерея изображений для каждого проекта
3. Фильтрация проектов по категориям

### Услуги агентства
1. Описание предоставляемых услуг
2. Карточки услуг с иконками и описанием

### Обратная связь
1. Контактная форма с полями: имя, email, сообщение
2. Валидация введенных данных
3. Отправка данных формы

### Информация о компании
1. Секция "О нас" с описанием агентства
2. Контактная информация

## Хранение данных
1. Статические данные портфолио в локальном хранилище
2. Данные услуг и информации о компании в конфигурационных файлах

# Use Case: "Просмотр портфолио и отправка заявки"

### Актор: Потенциальный клиент

### Предусловия:
- Пользователь находится на сайте рекламного агентства

### Основной поток:
1. Пользователь заходит на главную страницу
2. Система отображает навигационное меню и Hero секцию
3. Пользователь прокручивает до секции "Портфолио"
4. Система отображает grid с кейсами работ
5. Пользователь кликает на понравившийся кейс
6. Система открывает модальное окно с детальной информацией о проекте:
   - Название проекта
   - Описание задачи и решения
   - Галерея изображений
   - Использованные технологии
7. Пользователь просматривает галерею изображений проекта
8. Пользователь закрывает модальное окно и прокручивает до секции "Контакты"
9. Пользователь заполняет форму обратной связи:
   - Имя (обязательное поле)
   - Email (обязательное поле с валидацией)
   - Сообщение с описанием проекта
10. Пользователь нажимает кнопку "Отправить заявку"
11. Система валидирует данные формы
12. Система сохраняет заявку в localStorage
13. Система показывает сообщение об успешной отправке

### Альтернативные потоки:

- Пользователь хочет посмотреть все работы:
  1. Пользователь кликает "Смотреть все" в секции портфолио
  2. Система перенаправляет на страницу /portfolio
  3. Система отображает полную коллекцию работ с фильтрами по категориям

- Форма заполнена с ошибками:
  1. Система обнаруживает невалидные данные
  2. Система подсвечивает поля с ошибками
  3. Система показывает сообщения об ошибках под полями
  4. Пользователь исправляет ошибки и повторяет отправку

- Пользователь использует мобильное устройство:
  1. Система адаптирует интерфейс для мобильного просмотра
  2. Навигация преобразуется в бургер-меню
  3. Галерея изображений оптимизируется для тач-интерфейса

### Постусловия:
- Заявка клиента сохранена в системе
- Пользователь получил подтверждение отправки
- Агентство может просмотреть заявку в панели администратора

# AdCreator Bot

Telegram бот для создания и управления рекламными кампаниями.

## 🚀 Функциональность

- **Создание рекламных объявлений** - пошаговое создание кампаний для разных платформ
- **Аналитика кампаний** - просмотр статистики и эффективности
- **Проверка контента** - автоматическая проверка соответствия правилам площадок
- **Рекомендации по оптимизации** - AI-советы по улучшению кампаний
- **Шаблоны объявлений** - готовые шаблоны для разных платформ

## 📋 Поддерживаемые платформы

- 📷 Instagram
- 📘 Facebook  
- 📱 Telegram
- 👥 VK

## 🛠 Установка и настройка

### Предварительные требования

- Node.js 18+ 
- npm или yarn
- Аккаунт в Telegram
- Бот, созданный через @BotFather

### 1. Клонирование и установка

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd lab4-node/solutions/student-17

# Установите зависимости
npm install

---при необходимости---
npm install telegraf node-cron axios dotenv

```

### 2. Настройка окружения

```bash
# Создайте файл .env на основе примера
cp .env.example .env

# Отредактируйте .env файл
# Добавьте ваш токен бота от @BotFather
BOT_TOKEN=your_actual_bot_token
```

### 3. Получение токена бота

1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в файл `.env`

## 📚 Доступные команды бота

Ссылка на бота - @JSJSAK123_bot

### Основные команды
- `/start` - Начало работы с ботом
- `/create_ad` - Создание рекламного объявления
- `/analytics` - Просмотр аналитики кампаний  
- `/cancel` - Отмена текущей операции

### Процесс создания объявления
1. Выбор платформы (Instagram, Facebook, Telegram, VK)
2. Ввод текста объявления (макс. N символов)
3. Автоматическая проверка на соответствие правилам
4. Создание кампании с уникальным ID

## 🐛 Решение проблем

### Частые ошибки

**Ошибка: BOT_TOKEN is required**
```bash
# Решение: проверьте наличие .env файла
cat .env
# Убедитесь, что BOT_TOKEN указан правильно
```

**Ошибка: Cannot find module**
```bash
# Решение: переустановите зависимости
rm -rf node_modules
npm install
```

**Тесты не проходят**
```bash
# Решение: запустите с подробным выводом
npm test -- --verbose
```

### Логирование

Для отладки добавьте в код:
```javascript
console.log('Debug:', variable);
```
